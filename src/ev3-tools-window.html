💡 Советы по подключению по Bluetooth на Windows:
  • Включите Bluetooth на блоке EV3 (меню Settings → Bluetooth → Visibility & Bluetooth: ON).
  • В Windows откройте «Параметры → Bluetooth и устройства → Добавить устройство» (PIN-код: 1234).
  • Windows назначит входящий и исходящий виртуальный COM-порт (выберите исходящий порт в списке выше).
  • Для гарантированной передачи файлов большого размера на соревнованиях используйте USB-кабель.
