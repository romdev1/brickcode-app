# BrickCode App 🧱

Настольное приложение визуального редактора **BrickCode** для программирования роботов **LEGO MINDSTORMS EV3**.

Создана специально для использования на соревнованиях, выставках и в классах, где отсутствует постоянное подключение к интернету.

---

## Особенности

- 🌐 **Автоматическая синхронизация при наличии интернета**: при запуске приложение проверяет наличие обновлений на GitHub (`pxt-ev3-community/pxt-ev3`) и обновляет локальную копию.
- 📴 **Полная автономность офлайн**: если интернет недоступен, моментально открывается локально закэшированная версия редактора.
- 📦 **Локальный веб-сервер**: встроенный Express-сервер отдаёт все ресурсы редактора локально на `localhost`.
- 💻 **Удобная установка (Все пользователи или без прав админа)**: установщик позволяет выбрать режим установки — для всех пользователей системы (с правами администратора) или только для текущего пользователя (без необходимости прав администратора).
- 📡 **Выбор Bluetooth COM-порта (EV3)**: встроенное модальное окно для выбора и проверки COM-портов с автоопределением EV3 Bluetooth Serial Port.
- 📋 **Окно логов в настройках**: удобный просмотр логов работы приложения прямо из шестерёнки настроек (или по `Ctrl+Shift+L`).

---

## Архитектура

- **Electron** — оконное приложение и оболочка.
- **Express** — легковесный локальный HTTP-сервер для поддержки PXT SPA-архитектуры.
- **Adm-Zip** — распаковка дистрибутивов редактора в `AppData/Roaming`.
- **WiX Toolset + electron-builder** — генерация нативного MSI-пакета.

## Установка и запуск из исходников

### Требования
- [Node.js](https://nodejs.org/) (версия 18+)
- npm

### Запуск в режиме разработки
```bash
npm install
npm start
```

### Сборка установщиков
```bash
# Через PowerShell-скрипт (собирает как Setup .exe, так и .msi)
powershell -ExecutionPolicy Bypass -File build.ps1

# Либо через npm
npm run build
```
Готовые установщики `.exe` (NSIS с выбором режима установки) и `.msi` появятся в папке `dist/`.
